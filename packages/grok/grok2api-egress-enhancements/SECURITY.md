# Security policy

Do not publish real grok2api environment files, application configuration, databases, state volumes, proxy URLs, account credentials, client keys, administrator credentials, or unsanitized production logs with an issue or merge request.

When reporting a patch defect, include the upstream commit, patch SHA-256, failing test name, and a redacted stack trace. Replace node names, addresses, request IDs, account IDs, and tokens before publishing.

This repository distributes source patches only. It does not operate a hosted service and does not require user credentials.
